# Codex Web Studio

HTML, CSS, 순수 JavaScript로 만든 반응형 개인 소개 웹사이트입니다. 외부 라이브러리, CDN, 폰트 및 이미지 없이 동작합니다.

## 파일 구성

- `index.html` — 시맨틱 페이지 구조와 콘텐츠
- `style.css` — 밝은 테마, 프로젝트 카드, 반응형 레이아웃
- `script.js` — 프로젝트 영역 이동과 푸터 연도 표시

## 실행 방법

`index.html`을 브라우저에서 직접 열거나 프로젝트 루트에서 로컬 서버를 실행합니다.

```bash
python3 -m http.server 8000
```

이후 `http://localhost:8000`에 접속합니다.

## 배포 방법

### GitHub Pages

1. 저장소의 기본 브랜치에 네 웹사이트 파일을 푸시합니다.
2. GitHub 저장소의 **Settings → Pages**로 이동합니다.
3. **Deploy from a branch**를 선택하고 기본 브랜치의 `/ (root)`를 지정합니다.
4. 저장 후 표시되는 배포 주소에서 페이지를 확인합니다.

모든 리소스가 상대경로를 사용하므로 프로젝트 페이지 경로에서도 별도 수정 없이 동작합니다.

### Cloudflare Pages

1. Cloudflare 대시보드의 **Workers & Pages**에서 GitHub 저장소를 연결합니다.
2. 프로덕션 브랜치로 기본 브랜치를 선택합니다.
3. 프레임워크 프리셋은 **None**, 빌드 명령은 비워 두고, 빌드 출력 디렉터리는 저장소 루트를 뜻하는 `.`으로 설정합니다.
4. 배포 후 제공된 `pages.dev` 주소에서 메뉴, 스크롤 및 모바일 레이아웃을 확인합니다.

이 프로젝트에는 빌드 단계나 환경 변수가 필요하지 않습니다. 저장소에 API 키, 토큰 또는 `.env` 파일을 추가하지 마세요.

## 점검 사항

- 모바일 및 데스크톱 화면에서 레이아웃 확인
- Home, About, Projects 탐색 링크 확인
- `프로젝트 보기` 버튼의 부드러운 스크롤 확인
- 브라우저 개발자 도구 콘솔에서 오류 및 누락 리소스 확인
